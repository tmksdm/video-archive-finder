# Состояние проекта

## Текущий результат

Подготовлен воспроизводимый portable release candidate `1.0.0-rc.2` для Windows x64 с исправленной максимизацией окна.

## Подтверждённое состояние

- При максимизации главное окно ограничивается рабочей областью текущего монитора, поэтому строка состояния остаётся над панелью задач Windows.
- Release-скрипт собирает приложение, запускает тесты, проверяет структуру поставки и создаёт ZIP с SHA-256.
- В корне portable-папки находятся только `VideoArchiveFinder.exe` и `app`.
- В поставку входят FFmpeg, FFprobe, x64 LibVLC с плагинами и обязательные лицензии.
- EXE из portable-папки имеет продуктовую версию `1.0.0-rc.2`, запускается, корректно максимизируется и штатно завершается с кодом 0.
- Реальный MXF по UNC распознан как MPEG-2 4:2:2, получил метаданные и миниатюру; пользователь подтвердил hover scrubbing.
- После завершения просмотра и закрытия приложения MXF освобождён и доступен для эксклюзивного чтения.

## Проверки

- Нативная оконная проверка после системной команды максимизации — границы окна `0,0–2560,1400` совпали с рабочей областью монитора `0,0–2560,1400`.
- `dotnet build .\VideoArchiveFinder.sln` — успешно, 0 предупреждений, 0 ошибок.
- `dotnet test .\VideoArchiveFinder.sln --no-build` — 245 тестов пройдено, 0 ошибок.
- `.\scripts\New-PortableRelease.ps1 -Version 1.0.0-rc.2` — сборка без предупреждений и ошибок, 245 тестов пройдено; ZIP и файл SHA-256 созданы, структура поставки проверена.
- Запуск EXE из распакованного ZIP — окно отвечает и штатно завершается с кодом 0.
- MXF `05_02_Реконструкция_битвы_01-29.mxf` — FFprobe и FFmpeg из RC успешно обработали файл; hover scrubbing подтверждён пользователем; исходник не изменён и не заблокирован.

## Ограничения и блокеры

- Текущий компьютер содержит .NET SDK; запуск на отдельном Windows x64 без установленного .NET и VLC ещё требует ручной проверки.
- Ручная приёмка на разных DPI и разрешениях экрана для этого RC ещё не выполнена.
- Ранее замеченные пользователем UI-глюки ещё не описаны воспроизводимыми сценариями.

## Следующий результат

Провести ручную приёмку RC 2 на отдельном Windows-компьютере без установленного .NET и VLC; после успешной приёмки подготовить тег `v1.0.0`.
