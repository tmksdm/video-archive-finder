# Video Archive Finder

## Пользовательский результат

Пользователь быстро находит нужную папку в большом локальном или сетевом видеоархиве, просматривает найденные видео наведением мыши и перетаскивает выбранный файл в Adobe Premiere Pro.

## Целевая среда

- Платформа: Windows 10/11 x64.
- Пользователь: монтажёр или оператор видеоархива без требований к технической подготовке.
- Работа: локальные диски и UNC-ресурсы; поиск по локальному SQLite-индексу остаётся доступным при временной потере сети.
- Конфиденциальность: видео и пути не покидают компьютер пользователя; приложение не изменяет архив.

## Текущий минимальный сценарий

При выбранном видео, когда пользователь наводит мышь на область предпросмотра и двигает курсор по горизонтали, приложение без звука показывает кадр из соответствующей позиции ролика, а после ухода мыши останавливает проигрыватель и освобождает файл.

## Проверенное состояние этапа 6

- [x] MP4, MOV и MTS/M2TS открываются и позволяют переходить вперёд и назад.
- [x] Длинный ролик и ролик с длинным GOP не приводят к зависанию интерфейса.
- [x] UNC-файл работает, а потеря сети завершается понятной ошибкой без падения.
- [x] Первый кадр, CPU и память измерены и зафиксированы; звук отсутствует.
- [x] После ухода мыши локальный и сетевой файл освобождаются.
- [x] Повторное наведение и повторный выбор файла не оставляют проигрыватель или файл занятыми.
- [x] Один переиспользуемый проигрыватель интегрирован в карточки основной сетки и списка.

## Приёмка шага 6.4

- [x] Self-contained single-file сборка имеет в корне только `VideoArchiveFinder.exe` и папку `app`.
- [x] x64 LibVLC и плагины находятся в `app\libvlc`; x86 и ARM64 в поставку не входят.
- [x] Текст LGPL и уведомление об исходном коде находятся в `app\licenses\libvlc`.
- [x] Копия portable-папки запускается после переноса в другое расположение.
- [x] При отсутствии `app\libvlc` приложение не падает, отключает hover-просмотр и сохраняет остальные функции.
- [x] Пользователь вручную подтвердил hover scrubbing в перенесённой portable-сборке.

## Ограничения качества

- UI остаётся отзывчивым во время открытия и переходов.
- Одновременно существует не более одного `MediaPlayer`.
- Hover-кадры не записываются на диск.
- Нативные библиотеки загружаются только из `app\libvlc` относительно `AppContext.BaseDirectory`.

## Не входит в текущий шаг

- Несколько одновременных проигрывателей.
- Автоматическое управление размером кеша миниатюр.
- Drag-and-drop в Adobe Premiere Pro (этап 7).

## Команды проверки

- Сборка: `dotnet build .\VideoArchiveFinder.sln`
- Тесты: `dotnet test .\VideoArchiveFinder.sln --no-build`
- Portable-публикация: `dotnet publish .\src\VideoArchiveFinder.Desktop -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:PublishTrimmed=false`
