# Video Archive Finder

## Пользовательский результат

Пользователь быстро находит нужную папку в большом локальном или сетевом видеоархиве, просматривает найденные видео наведением мыши и перетаскивает выбранный файл в Adobe Premiere Pro.

## Целевая среда

- Платформа: Windows 10/11 x64.
- Пользователь: монтажёр или оператор видеоархива без требований к технической подготовке.
- Работа: локальные диски и UNC-ресурсы; поиск по локальному SQLite-индексу остаётся доступным при временной потере сети.
- Конфиденциальность: видео и пути не покидают компьютер пользователя; приложение не изменяет архив.

## Текущий минимальный сценарий

При выбранном видео, когда пользователь наводит мышь на область предпросмотра и двигает курсор по горизонтали, приложение без звука показывает кадр из соответствующей позиции ролика, а после ухода мыши останавливает проигрыватель и освобождает файл.

Поисковый индекс содержит папки, их названия и пути. Видеофайлы не перечисляются и не анализируются во время полного обхода архива. При открытии найденной папки приложение обновляет список файлов непосредственно в ней, сохраняет его в локальном кэше и в фоне создаёт метаданные и статические миниатюры только для открытой папки.

## Ограничения качества

- UI остаётся отзывчивым во время открытия и переходов.
- Одновременно существует не более одного `MediaPlayer`.
- Hover-кадры не записываются на диск.
- Нативные библиотеки загружаются только из `app\libvlc` относительно `AppContext.BaseDirectory`.

## Приёмка автоматического лимита кэша

- [x] Максимальный размер кэша равен 5% ёмкости диска, но не более 20 ГБ.
- [x] Программа сохраняет свободными минимум 10 ГБ или 10% диска — что больше.
- [x] При превышении лимита сначала удаляются давно не использовавшиеся миниатюры; очистка стремится к 90% лимита.
- [x] Недавно созданная миниатюра защищена от удаления во время текущей операции.
- [x] После удаления миниатюры её состояние в SQLite сбрасывается, поэтому файл может быть создан заново.
- [x] Очистка запускается при старте и после создания новых миниатюр без блокировки интерфейса.
- [x] Текущий размер и рассчитанный автоматический лимит показаны в окне настроек кэша.
